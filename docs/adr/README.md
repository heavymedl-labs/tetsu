# Architecture Decision Records

Every significant decision gets an ADR that cites reputable design-pattern
sources. Copy [`template.md`](template.md), number it next in sequence, and open it
in a pull request with status `proposed`. Merge flips it to `accepted`. Never edit
an accepted ADR's decision; supersede it with a new one.
